## Key conventions

- **Language:** comments, error messages, and documentation are in Spanish.
- **Line endings:** `.sh` and `.sql` files must use LF (enforced by `.gitattributes`).
- **SQL files under `concurrencia/`** are psql fragments that use variables (`:nivel`, `:modo`, `:primero`, `:segundo`) set by `laboratorio_concurrencia.sh`. They cannot be run standalone.
- **Generated `.sql` files** must not contain `BEGIN`, `COMMIT`, or `ROLLBACK` — transactions are managed by the scripts in `scripts/`.
- **`foodstore_plantilla`** is read-only. All writes go to `foodstore_trabajo` only.
- **`evidencias/`** files contain intentional errors (invalid test cases). Never remove or "fix" them.
- **Schema naming:** tables in singular `snake_case`; PK always `id BIGINT GENERATED ALWAYS AS IDENTITY`; FK columns named `<table>_id`.
- **`food-store/schema.sql`** is a copy of `../semana1_modelo_er_normalizacion_ddl/schema.sql` — keep them in sync when modifying.
- **`food-store/data.sql`** looks up rows by `nombre`/`email`; never hardcode IDs.
- **Before writing any file**, propose a plan and wait for confirmation.
