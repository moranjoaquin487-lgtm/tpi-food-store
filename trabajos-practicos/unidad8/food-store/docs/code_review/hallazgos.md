# Code review con IA — hallazgos y decisiones (TP8, consigna 3.c)

- **Presentado por:** Moran, Joaquín Leandro
- **Revisión:** OpenCode, agente **Plan** (modelo Big Pickle), abierto en la raíz del repo `tpi-food-store`, sin permiso para modificar archivos. Revisó todos los `.sql` y `.sh` de `sql/` (TPI, Unidades 1 a 3), `trabajos-practicos/unidad1/` y `trabajos-practicos/unidad8/food-store/`. La conversación completa está en [`revision_opencode.md`](revision_opencode.md).
- **Comprobación:** cada decisión se tomó después de probar el hallazgo en la base o de leer el script. [`comprobar_hallazgos.sh`](comprobar_hallazgos.sh) repite las comprobaciones en la base y deja la salida en `evidencias/3c_code_review.txt` (PostgreSQL 18.6 y SQLite 3.54.1).
- **Resultado:** 34 hallazgos. 16 aceptados, 7 corregidos y 11 descartados.

Aceptado quiere decir que el problema es real y queda para la entrega final del TPI, porque el script es de una unidad ya entregada. Corregido quiere decir que se cambió en este TP. Descartado quiere decir que, después de comprobarlo, no se cambia, por el fundamento que se indica.

## Antes de esta revisión

La primera versión del TP8 la escribió Claude, y Claude hizo una primera revisión de esos scripts. De ahí salió una corrección que sigue vigente: `cargar_snapshot.sql` copia la instantánea **por nombre de columna**, porque `.import --skip 1` llenaba por posición, y con las columnas en otro orden la Muzzarella quedaba a $0,40 sin ningún error. Está en la bitácora (`docs/bitacora_ia.md`).

OpenCode revisó solo `.sql` y `.sh`, pero cargó automáticamente el `AGENTS.md` de la Semana 2 (OpenCode lo hace con la carpeta de cada archivo que lee) y leyó `docs/opencode/version_claude/` y el script de comprobaciones anterior, que nombraba hallazgos propios. Por eso #14, #27 y #28 se comparan con «la versión de Claude».
